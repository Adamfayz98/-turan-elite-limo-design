---
name: Homepage responsive parity
description: Project rule requiring deliberate desktop and mobile versions of every Turan homepage change.
---

Every TuranEliteLimo homepage change must be visually reviewed on both desktop and mobile; sections need deliberate responsive compositions rather than scaled-down desktop layouts.

**Why:** Desktop and mobile share the same content hierarchy and visual direction, but each section needs breakpoint-specific spacing, stacking, cropping, type, and touch-target decisions.

**How to apply:** Check desktop, tablet, and phone widths before delivery. Keep the horizontal takeover on desktop and the stacked booking flow on mobile; this booking behavior is the only major responsive exception.

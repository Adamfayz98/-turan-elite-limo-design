==================================================
1. CORE MOTION PHILOSOPHY
==================================================

Use two kinds of motion:

A. ONE-TIME REVEALS

Used for:
- small labels
- section headings
- numbers
- buttons
- short text groups

These can animate once when entering the viewport.

B. SCROLL-LINKED MOTION

Used for:
- larger visual sections
- app section
- Turan Standard
- major editorial compositions
- selected section exits

These should respond to actual scroll progress.

Important:

If the user scrolls slowly:
the animation progresses slowly.

If the user stops scrolling:
the animation should stop.

If the user scrolls faster:
the animation should progress accordingly.

Do NOT make everything fire as a fixed-duration animation regardless of scroll speed.

==================================================
2. MOTION CHARACTER
==================================================

Motion should feel:

- composed
- smooth
- premium
- quiet
- cinematic
- editorial

Avoid:

- bouncing
- spring effects
- dramatic zooms
- spinning
- exaggerated parallax
- elastic movement
- fast flashy fades
- large rotations
- random movement
- different animation styles in every section

Use a consistent visual language.
